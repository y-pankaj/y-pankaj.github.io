--- layout: default title: Side Quests permalink: /side-quests/ description: A lifetime list, where some of the entries keep their own score. comments: true --- {%- comment -%} The list itself lives in _data/quests.yml. Quests with a `track` block resolve against live site data through _includes/quest-value.html, so the half marathon, the bench, the continent count and the post count update themselves and cannot go stale the way a hand-edited checklist does. The counting pass below has to repeat that resolution, because Liquid has no way to carry a computed list out of one loop and into another. It is 24 items; the duplication is cheaper than a build step. {%- endcomment -%} {%- assign quests = site.data.quests -%} {%- assign total = quests | size -%} {%- assign done_n = 0 -%} {%- assign prog_n = 0 -%} {%- for q in quests -%} {%- assign is_done = false -%} {%- if q.done -%}{%- assign is_done = true -%}{%- endif -%} {%- if q.track -%} {%- capture raw %}{% include quest-value.html quest=q %}{% endcapture -%} {%- assign val = raw | strip | split: '|' | first | plus: 0.0 -%} {%- assign tgt = q.track.target | plus: 0.0 -%} {%- if val >= tgt -%} {%- assign is_done = true -%} {%- elsif val > 0 -%} {%- assign prog_n = prog_n | plus: 1 -%} {%- endif -%} {%- endif -%} {%- if is_done -%}{%- assign done_n = done_n | plus: 1 -%}{%- endif -%} {%- endfor -%} {%- assign todo_n = total | minus: done_n | minus: prog_n -%} {%- assign done_pct = done_n | times: 100.0 | divided_by: total -%} {%- assign prog_pct = prog_n | times: 100.0 | divided_by: total -%}

I’m a big fan of to-dos and checklists, and I’ve always wanted a list of personal side quests to complete in my lifetime. After seeing Chip Huyen’s list, I couldn’t resist making my own. A few of these keep their own score — the running and lifting ones read straight off the training log, the continents off the map, and the writing one off this site — so the numbers below are whatever is true today.
