--- layout: default title: Travel permalink: /travel/ description: Everywhere I have been, and the seven-continent side quest it feeds. comments: true wip: Still adding places, and the photos to go with them. --- {%- comment -%} Places come from _data/travel.yml; the outlines from _includes/world-land.svg, which scripts/build_world_map.py generates from Natural Earth, with India's states and union territories as a second layer once it has been run with --states. Fills are resolved at build time by the style block below, and the default view is worked out here rather than in JavaScript so that the first paint is already the right one -- assets/js/travel.js reads this viewBox back as its "home" view instead of recomputing the fit, which keeps the fitting logic in one place. Without JavaScript you get a correct, static, pre-framed map whose markers link down to the list; zooming, clustering and the hover card are the enhancement on top. {%- endcomment -%} {%- assign places = site.data.travel | sort: 'when' | reverse -%} {%- assign isos = site.data.travel | map: 'iso' | compact | uniq -%} {%- assign visited = site.data.travel | map: 'continent' | compact | uniq -%} {%- assign wm = site.data.world_map -%} {%- assign all_continents = 'Asia,Europe,Africa,North America,South America,Oceania,Antarctica' | split: ',' -%} {%- assign kinds = 'trek,city,coast,home' | split: ',' -%} {%- comment -%} States visited, as slugs, since that is what the map's ids are made of. With the state layer built they are checked against it, so a misspelt state neither fills anything nor counts. {%- endcomment -%} {%- capture state_slugs -%} {%- for p in site.data.travel -%} {%- if p.iso == 'IND' and p.state -%} {%- assign s = p.state | slugify -%} {%- if wm.states == nil or wm.states[s] -%}{{ s }},{%- endif -%} {%- endif -%} {%- endfor -%} {%- endcapture -%} {%- assign state_slugs = state_slugs | split: ',' | uniq -%} {%- comment -%} The map's x is longitude times x_scale (see _data/world_map.yml); y is minus the latitude. Everything below works in degrees and scales x at the end, so the data file can stay in degrees too. {%- endcomment -%} {%- assign k = wm.x_scale | default: 1.0 -%} {%- comment -%} The default view. Fitted to the pins unioned with the full extent of every country visited -- the countries matter because framing on the pins alone crops the country they sit in. The southernmost Indian pin is Bengaluru, so a pin-only fit cut off everything below it, Kanyakumari and all. Country extents come from _data/world_map.yml, which the generator writes alongside the outlines. That box is then padded, floored at 16 degrees of latitude so two pins in one city do not zoom to street level, and widened to the 1.2 aspect ratio the stylesheet gives the map box (India is taller than it is wide, so a wider box spent most of itself on sea). Today it lands on the subcontinent. Add a pin in Europe and it opens out on its own, which is why it is fitted rather than hardcoded to India. {%- endcomment -%} {%- assign map_aspect = 1.2 -%} {%- assign lons = site.data.travel | map: 'lon' | compact | sort -%} {%- assign lats = site.data.travel | map: 'lat' | compact | sort -%} {%- assign world_w = wm.width | times: k -%} {%- assign world_x = wm.lon_min | times: k -%} {%- if lons.size > 0 -%} {%- assign lon_lo = lons | first -%} {%- assign lon_hi = lons | last -%} {%- assign lat_lo = lats | first -%} {%- assign lat_hi = lats | last -%} {%- for iso in isos -%} {%- assign bounds = wm.countries[iso] -%} {%- if bounds -%} {%- if bounds[0] < lon_lo -%}{%- assign lon_lo = bounds[0] -%}{%- endif -%} {%- if bounds[1] < lat_lo -%}{%- assign lat_lo = bounds[1] -%}{%- endif -%} {%- if bounds[2] > lon_hi -%}{%- assign lon_hi = bounds[2] -%}{%- endif -%} {%- if bounds[3] > lat_hi -%}{%- assign lat_hi = bounds[3] -%}{%- endif -%} {%- endif -%} {%- endfor -%} {%- assign lat_span = lat_hi | minus: lat_lo | times: 1.12 -%} {%- if lat_span < 16 -%}{%- assign lat_span = 16 -%}{%- endif -%} {%- assign lon_span = lon_hi | minus: lon_lo | times: 1.12 | times: k -%} {%- assign lon_needed = lat_span | times: map_aspect -%} {%- if lon_span < lon_needed -%}{%- assign lon_span = lon_needed -%}{%- endif -%} {%- if lon_span > world_w -%}{%- assign lon_span = world_w -%}{%- endif -%} {%- assign lat_span = lon_span | divided_by: map_aspect -%} {%- assign half_lon = lon_span | divided_by: 2.0 -%} {%- assign half_lat = lat_span | divided_by: 2.0 -%} {%- assign centre_x = lon_lo | plus: lon_hi | divided_by: 2.0 | times: k -%} {%- assign centre_lat = lat_lo | plus: lat_hi | divided_by: 2.0 -%} {%- assign vb_x = centre_x | minus: half_lon -%} {%- assign vb_y = 0.0 | minus: centre_lat | minus: half_lat -%} {%- comment -%} Keep it inside the world;
